# Official Mascot Source Images

本目录保存首师附一小官方吉祥物的一级视觉参考图。

这些文件用于：

- 锁定角色身份
- 校验新动作的一致性
- 生成教材扩展动作
- 生成科技专题形象
- 防止 AI 根据文字描述重新设计角色

## 文件映射

| 文件 | 角色 / 用途 | 优先级 |
|---|---|---:|
| `tiangcheng-standard.png` | 甜橙标准形象 | P0 |
| `yangguang-standard.png` | 阳光标准形象 | P0 |
| `xiaoyi-standard.png` | 小一标准形象 | P0 |
| `tech-extension-reference.png` | 科技专题装备、坐姿、护目镜、耳机、科技屏参考 | P1 |

## 使用原则

### P0：身份基准

生成甜橙、阳光或小一时，首先保持对应 P0 图中的：

- 角色轮廓
- 五官
- 头身比例
- 服装
- 红领巾
- 学校标识
- 鞋子
- 主要配色
- 描边风格

### P1：扩展参考

`tech-extension-reference.png` 只用于：

- 耳机
- 护目镜
- 平板 / 科技屏
- 科技专题坐姿
- 计算思维 / 信息科技专题装备

不得用 P1 图覆盖或改变 P0 图定义的角色身份。

## 新动作生成顺序

1. 选择角色 P0 标准图。
2. 阅读 `../MASCOT-GUIDE.md`。
3. 根据课程维度确定动作与教学道具。
4. 如为科技专题，再参考 P1 图。
5. 只改变动作、表情、手势和允许的道具。
6. 输出独立、透明背景角色素材。

## 文件维护

如果后续获得更高质量官方原稿：

- 不随意删除历史版本；
- 建议使用 `-v2`、`-v3` 等版本号；
- 确认新版成为正式标准后，再同步更新 MASCOT-GUIDE。

## 命名说明

当前甜橙标准图文件名为：

`tiangcheng-standard.png`

从拼音规范角度，后续可考虑统一为：

`tiancheng-standard.png`
