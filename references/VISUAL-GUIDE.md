# Visual Guide — 首师附一小《计算思维》初阶教材

## 1. 视觉定位

关键词：

- 温暖
- 清晰
- 活泼
- 克制
- 小学生友好
- 精品教材感
- 不幼儿化
- 不游戏化
- 不电商化

核心原则：

> 内容优先、留白优先、统一优先。

## 2. 主色系统

- 暖橙（主色）：`#C87D4F`
- 暖金（强调）：`#C69A5E`
- 赤陶（重点）：`#B2603C`
- 暖棕（辅助）：`#8A5A3B`
- 米杏（浅底）：`#F8EBE0`
- 墨棕（正文 / 深描边）：`#3D3630`

功能辅助色仅少量使用：

- 柔黄：`#F4C95D`
- 柔绿：`#9BCB8B`
- 浅蓝：`#8EC5E8`

## 3. 标题字

默认效果：

1. 粗圆、饱满中文
2. 暖橙—橙红渐变
3. 左上少量柔和高光
4. 深棕描边
5. 白色贴纸外轮廓
6. 很轻的阴影

禁止：

- 霓虹
- 金属
- 强 3D
- 毛笔字
- 电商促销字
- 游戏 Logo 风

## 4. 页面密度

小学低段页面必须控制信息量：

- 单页 1 个明确视觉中心
- 吉祥物原则上不超过有效面积 20%–25%
- 同页大装饰元素不超过 3 个
- 学生作答空间优先于装饰
- 正文和活动框必须保留明显留白

## 5. 五类思维视觉语义

- 观察：放大镜、眼睛、细节卡
- 推理：线索卡、比较、路径、对话气泡
- 空间：积木、立方体、拼图形
- 规律：序列点、循环箭头、重复图案
- 生活：时钟、钱币、购物篮、日程、生活物品

科技类元素（电脑、代码、齿轮）只在具体内容需要时出现。

## 6. 默认页面栏目

- 一起发现
- 动手探一探
- 我发现了
- 思维小妙招
- 换一换，再试试
- 我的思维星

单元收束：

- 我的思维地图
- 思维大闯关
- 这一站，我成长了！

## 7. 素材输出

优先使用独立、透明背景素材，方便在 Figma、Photoshop、Canva、PPT 或专业排版软件中二次组合。

- 标题：2048×768 PNG
- 图标：1024×1024 PNG
- 吉祥物：1536×1536 PNG
- 栏目标签：1600×600 PNG

## 8. 中文文字规则

正式教材必须优先保证文字准确。

AI 图片中的中文若出现错字、漏字、笔画错误，不应直接用于出版成稿。正式出版模式建议使用真实字体排版，AI 只负责字效、装饰与视觉参考。
