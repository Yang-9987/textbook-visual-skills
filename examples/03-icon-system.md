# Case 03 — 统一图标系统

## 先建立“五把思维钥匙”核心图标

> 使用 primary-school-textbook-visual-system Skill，生成 5 个独立教材图标：放大镜、线索卡/对话气泡、立方体积木、循环序列、生活小房子。分别对应观察、推理、空间、规律、生活。统一橙金配色、深棕描边、圆润卡通风，每个图标单独居中，透明背景，不要文字。

## 核心思维图标

| 图标 | 用途 |
|---|---|
| 放大镜 | 观察 |
| 线索卡 / 对话气泡 | 推理 |
| 立方体 / 积木 | 空间 |
| 序列点 / 循环箭头 | 规律 |
| 小房子 / 时钟 / 钱币 | 生活 |
