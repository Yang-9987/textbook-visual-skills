# Case 03 — 统一图标系统

## 一次生成一组

> 使用 primary-school-textbook-visual-system Skill，生成 6 个独立教材图标：灯泡、放大镜、拼图、齿轮、靶心、铅笔。统一橙金配色、深棕描边、圆润卡通风，每个图标单独居中，透明背景，不要文字。

## 推荐语义

| 图标 | 用途 |
|---|---|
| 灯泡 | 想法 / 提示 |
| 放大镜 | 观察 |
| 拼图 | 分解 / 组合 |
| 齿轮 | 算法 / 机制 |
| 靶心 | 学习目标 |
| 铅笔 | 记录 / 练习 |
| 书本 | 阅读 / 知识 |
| 小旗 | 挑战任务 |
| 星星 | 收获 / 评价 |

## 使用建议

正文页优先使用简洁图标，不要每个栏目都搭配复杂插画。
