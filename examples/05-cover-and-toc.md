# Case 05 — 封面 / 扉页 / 目录的统一延展

## 封面

建议拆分：

- “计算思维”主标题字
- “教材模板 / 第 X 册”副标题标签
- 主吉祥物
- 编程机器人
- 纸飞机
- 灯泡
- 拼图
- 书本
- 波浪页脚

不要一次性把所有元素烘焙进一张图。

## 扉页

减少装饰：

- 主标题
- 吉祥物单角色
- 学校 / 班级 / 姓名信息框
- 少量纸飞机或星星

## 目录

重点是信息层级：

- “目录”标题
- 6 个单元数字标签
- 每单元一个简洁图标
- 右侧学习目标 / 关键词信息框
- 吉祥物只占页面约 15%–20%

## 调用示例

> 使用 primary-school-textbook-visual-system Skill，给“目录”生成一个独立标题字素材。比“计算思维”主标题小一级，橙红渐变，深棕描边，白色贴纸边，透明背景，不加人物。
