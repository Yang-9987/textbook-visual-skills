# Case 05 — 封面 / 扉页 / 目录的统一延展

## 封面

建议拆分：

- “计算思维”主标题字
- “初阶 / 第 X 册”等副标题标签
- 主吉祥物
- 纸飞机
- 灯泡
- 放大镜
- 积木 / 数字 / 图形等低段思维元素
- 书本
- 波浪页脚

编程机器人和代码符号不是封面必选项；只有确实符合课程定位时少量使用。

不要一次性把所有元素烘焙进一张图。

## 扉页

推荐标题：

**你好，思维世界！**

减少装饰：

- 主标题
- 吉祥物单角色
- 学校 / 班级 / 姓名信息框
- 少量纸飞机或星星

## 前置页面

建议配套设计：

1. 写给小小思考家的话
2. 认识我们的思维伙伴
3. 这本书怎么学？
4. 五把思维钥匙
5. 思维探险地图

## 五把思维钥匙

- 观察
- 推理
- 空间
- 规律
- 生活

每把钥匙使用独立图标，并保持同一视觉语言。

## 目录

重点是信息层级。

当前教材建议按 5 个单元组织：

1. 睁大眼睛看世界
2. 规律藏在哪里？
3. 数字也会变魔法
4. 我是逻辑小侦探
5. 生活中的思维魔法

目录页建议包含：

- “思维探险地图”或“目录”标题
- 5 个单元标签
- 单元下列课题
- 每单元一个代表性图标
- 吉祥物只占页面约 15%–20%

## 调用示例

> 使用 primary-school-textbook-visual-system Skill，给“思维探险地图”生成一个独立目录标题字素材。比“计算思维”主标题小一级，橙红渐变，深棕描边，白色贴纸边，透明背景，不加人物。
