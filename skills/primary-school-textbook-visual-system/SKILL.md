# Skill: Primary School Textbook Visual System

## Purpose

为首师附一小小学《计算思维》教材生成统一视觉资产。所有输出优先满足：

1. 教材可读性
2. 体系一致性
3. 小学生亲和力
4. 内容与思维目标匹配
5. 装饰性

本 Skill 的默认课程基线是“低段计算思维启蒙”，而不是“编程教材”。

---

## Course baseline

当前教材面向小学低段零基础思维启蒙。

默认课程关注五类思维维度：

- 观察
- 推理
- 空间
- 规律
- 生活

视觉表达应支持孩子：

- 看得细、找得全
- 会比较、会推理
- 能理解图形与空间
- 能发现变化和规律
- 能把思考方法迁移到生活情境

算法、流程图、编程可以出现，但只能在具体课程需要时使用，不能作为整本教材的默认视觉中心。

---

## Default learning journey

整本书默认使用以下五步学习路径：

1. **发现** — 看一看，有什么特别？
2. **探索** — 动手试一试。
3. **整理** — 我发现了什么规律或方法？
4. **迁移** — 换一个问题，我也会。
5. **成长** — 我的思维又升级了。

页面视觉应帮助学生感知这条学习路线，而不是强制每课套用“问题分解—算法—编程”。

---

## Default book structure

### Front matter

建议默认使用：

1. 封面
2. 扉页：**你好，思维世界！**
3. 编者的话：**写给小小思考家的话**
4. 吉祥物介绍：**认识我们的思维伙伴**
5. 使用说明：**这本书怎么学？**
6. 能力地图：**五把思维钥匙**
7. 目录：**思维探险地图**

### Five thinking keys

能力地图默认使用：

- 🔍 观察钥匙
- 🕵️ 推理钥匙
- 🧊 空间钥匙
- 🔁 规律钥匙
- 🏠 生活钥匙

图标需转换为同一套教材插画语言，不直接使用 emoji。

### Default lesson sections

每课优先采用：

1. **一起发现**
2. **动手探一探**
3. **我发现了**
4. **思维小妙招**
5. **换一换，再试试**
6. **我的思维星**

### Unit wrap-up

每单元结束可使用：

- **我的思维地图**
- **思维大闯关**
- **这一站，我成长了！**

这些标题是默认栏目语言。用户提供其他教材结构时，应优先尊重用户的新结构。

---

## Use this skill when

用户请求以下任一内容时使用：

- 教材主标题、单元标题、课题标题、活动标题
- 栏目标签
- 计算思维图标
- 吉祥物动作
- 页面装饰元素
- 页面辅助组件
- 封面、扉页、目录的视觉资产拆分
- 与既有教材风格保持一致的视觉素材

## Do not use this skill when

- 用户明确要求写实风
- 用户明确要求书法、毛笔字
- 用户要求完全不同的品牌视觉
- 用户只需要普通正文排版

---

## Visual language

整体关键词：

- 温暖
- 活泼
- 清晰
- 亲和
- 小学生友好
- 不幼稚
- 不花哨
- 教材感强

目标感觉：

> 精品小学教材中的视觉资产，而不是儿童游戏 Logo、电商促销海报或玩具包装。

# Asset type A: Cartoon title typography

## A1. Main title

适合：

- 计算思维
- 册名
- 封面主标题

### Shape

- 中文粗圆字体
- 字形饱满
- 转角圆润
- 略带手写变化
- 不使用细字体
- 不使用尖锐字形
- 可轻微错落，但整体稳定

### Layer stack

从内到外：

1. 橙红主体
2. 左上柔和高光
3. 深棕粗描边
4. 白色贴纸外轮廓
5. 很轻的暖棕阴影

### Suggested title gradient

顶部：#FF9A32  
中部：#F47B25  
底部：#D9572E

深描边：#3D3630 或 #4A281C

### Composition

- 标题居中
- 四周留安全边距
- 默认透明背景
- 不加入正文
- 不加入人物
- 装饰元素最多 0–3 个

### Optional micro decorations

优先选择和课程维度有关的元素：

- 放大镜：观察
- 对话 / 线索：推理
- 积木 / 立方体：空间
- 循环箭头 / 序列点：规律
- 时钟 / 钱币 / 生活物品：生活
- 灯泡：想法
- 星星：成长
- 纸飞机：探索

齿轮、代码符号、电脑仅在具体课程确实涉及算法或编程时使用。

### Text accuracy

文字准确性为最高优先级。

必须逐字匹配用户输入：

- 不漏字
- 不多字
- 不换字
- 不擅自加英文
- 不生成乱码

---

## A2. Unit title

默认单元风格比封面主标题小一级，可搭配一个代表该单元思维维度的图标。

当前项目推荐的单元标题范式：

- 睁大眼睛看世界
- 规律藏在哪里？
- 数字也会变魔法
- 我是逻辑小侦探
- 生活中的思维魔法

这些是当前教材的视觉组织建议，不应在用户更新课程大纲后强制保留。

---

## A3. Lesson title

适合具体课题，例如：

- 立体积木太空站
- 数字森林找秘密
- 图形王国变变变
- 奇偶小精灵魔法
- 小小侦探比一比
- 真相只有一个
- 时光小管家
- 小小超市采购员

要求：

- 比单元标题更简洁
- 保留橙红 / 暖金体系
- 深棕描边
- 白色贴纸边可减弱
- 装饰最多 1 个
- 优先体现本课内容，而不是固定加入编程符号

---

## A4. Section title

适合：

- 一起发现
- 动手探一探
- 我发现了
- 思维小妙招
- 换一换，再试试
- 我的思维星
- 我的思维地图
- 思维大闯关
- 这一站，我成长了！

要求：

- 轻量
- 读起来清楚
- 可配一个功能图标
- 不抢正文主视觉

# Asset type B: Section labels

栏目标签默认语义：

- 一起发现 → 放大镜 / 眼睛
- 动手探一探 → 手 / 铅笔 / 操作物
- 我发现了 → 灯泡
- 思维小妙招 → 小钥匙 / 小灯泡
- 换一换，再试试 → 循环箭头
- 我的思维星 → 星星
- 我的思维地图 → 地图 / 节点
- 思维大闯关 → 小旗 / 奖杯
- 这一站，我成长了！ → 幼苗 / 足迹

样式：

- 圆角胶囊 / 圆角矩形
- 暖橙或米杏底
- 深棕文字
- 左侧可配一个小图标
- 轻微投影
- 不使用厚重立体效果

# Asset type C: Icons

统一规则：

- 卡通扁平 + 轻微立体
- 粗细一致的圆润描边
- 透明背景
- 单图标独立输出
- 小学生友好
- 与教材主题色统一

## Core thinking icon set

优先建立：

- 放大镜：观察
- 线索 / 对话气泡：推理
- 立方体 / 积木：空间
- 序列点 / 循环箭头：规律
- 小房子 / 时钟 / 钱币：生活

## Learning action icons

- 灯泡：发现 / 想法
- 铅笔：记录
- 书本：学习
- 对话框：交流
- 小旗：挑战
- 星星：成长 / 收获
- 箭头：步骤
- 拼图：拆分 / 组合
- 靶心：学习目标

## Optional technology icons

只有课程明确需要时使用：

- 齿轮：算法 / 机制
- 电脑：信息技术
- </>：编程

# Asset type D: Mascot

基于用户提供的橙色果实吉祥物保持一致性。

必须保持：

- 头部轮廓
- 橙色果实外形
- 绿色叶片
- 大眼睛
- 白橙校服
- 红领巾
- 线条风格
- 主色关系

允许变化：

- 动作
- 表情
- 手势
- 道具
- 姿态

推荐动作按五类思维扩展：

### 观察
- 拿放大镜
- 趴近观察
- 指向细节

### 推理
- 托腮思考
- 看线索卡
- 指向两个比较对象

### 空间
- 拿积木
- 旋转立方体
- 拼图形

### 规律
- 指向数字序列
- 排列图案
- 展示循环卡片

### 生活
- 看时钟
- 拿购物篮
- 使用钱币
- 整理物品

### 通用
- 挥手
- 举灯泡
- 拿铅笔
- 阅读
- 点赞
- 庆祝
- 完成任务

输出：

- 默认透明背景
- 单角色
- 不生成复杂场景

# Asset type F: Page components

适合生成：

- 页眉条

- 页码标签

- 提示框
- 思考框
- 学习任务框
- 作答框
- 观察记录框

视觉规则：

- 米杏浅底

- 适度圆角
- 留白充分
- 避免过厚边框
- 避免复杂纹理

---

# Page density rules

由于教材面向小学低段：

- 单页只设 1 个明确视觉中心
- 吉祥物原则上不超过页面有效面积的 20%–25%
- 同页大装饰元素不超过 3 个
- 正文区必须有充足留白
- 活动题的作答空间优先于装饰
- 同一页不同时使用过多功能色

# Prompt construction

## Title prompt template

创建一个独立中文教材标题素材。

文字必须准确写为：

「{TITLE}」

类型：

{TITLE_TYPE}

课程维度：

{THINKING_DIMENSION}

风格：小学低段计算思维教材卡通立体贴纸标题字。

要求：

- 粗圆中文字体
- 暖橙到橙红渐变
- 少量左上高光
- 深棕粗描边
- 白色贴纸外轮廓
- 很轻的立体阴影
- 活泼、温暖、清晰
- 根据课程维度选择最多 1 个小装饰
- 不要游戏 Logo 感
- 不要电商感
- 不要人物
- 不要页面
- 不要额外文字
- 不要擅自加入英文
- 默认透明背景
- 四周留安全边距

## Mascot prompt template

基于既有橙色果实吉祥物形象，保持头部轮廓、绿色叶片、大眼睛、白橙校服和红领巾一致。

课程维度：

{THINKING_DIMENSION}

生成动作：

{ACTION}

要求：

- 小学教材插画风
- 角色比例稳定
- 面部特征稳定
- 线条清晰
- 色彩与教材统一
- 道具优先与本课知识内容匹配
- 透明背景
- 不添加复杂场景
- 不添加文字

## Icon prompt template

生成一个小学低段计算思维教材风格图标：

{ICON}

对应思维维度：

{THINKING_DIMENSION}

要求：

- 卡通扁平 + 轻微立体
- 圆润线条
- 以橙、暖黄、暖棕为主
- 可少量使用浅绿、浅蓝
- 独立图标
- 透明背景
- 无文字
- 无场景
- 适合教材排版

# Design principles

始终遵守：

1. 内容 > 装饰
2. 字 > 装饰
3. 清晰 > 花哨
4. 教材感 > 游戏感
5. 统一 > 炫技
6. 小学生亲和 > 幼儿化
7. 留白 > 堆元素
8. 信息层级 > 装饰密度
9. 课程思维目标 > 固定科技符号
10. 真实学习活动 > 抽象“AI / 编程感”

最终视觉应像：

> 同一本首师附一小小学《计算思维》初阶教材中自然延伸出来的统一资产。
