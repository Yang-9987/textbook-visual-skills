# Skill: Primary School Textbook Visual System

## Purpose

为小学《计算思维》教材生成统一的视觉资产。所有输出优先满足“教材可读性、统一性、亲和力”，其次才是装饰性。

## Use this skill when

用户请求以下任一内容时使用：

- 教材主标题、章节标题、活动标题
- 栏目标签
- 计算思维图标
- 吉祥物动作
- 页面装饰元素
- 页面辅助组件
- 与既有教材风格保持一致的视觉素材

## Do not use this skill when

- 用户明确要求写实风
- 用户明确要求书法、毛笔字
- 用户要求完全不同的品牌视觉
- 用户只需要普通正文排版

---

## Visual language

整体关键词：

- 温暖
- 活泼
- 清晰
- 亲和
- 小学生友好
- 不幼稚
- 不花哨
- 教材感强

目标感觉：

> 精品小学教材中的视觉资产，而不是儿童游戏 Logo、电商促销海报或玩具包装。

# Asset type A: Cartoon title typography

## A1. Main title

适合：

- 计算思维
- 信息科技
- 人工智能
- 单元主标题

### Shape

- 中文粗圆字体
- 字形饱满
- 转角圆润
- 略带手写变化
- 不使用细字体
- 不使用尖锐字形
- 可轻微错落，但整体稳定

### Layer stack

从内到外：

1. 橙红主体
2. 左上柔和高光
3. 深棕粗描边
4. 白色贴纸外轮廓
5. 很轻的暖棕阴影

### Suggested title gradient

顶部：#FF9A32  
中部：#F47B25  
底部：#D9572E

深描边：#3D3630 或 #4A281C

### Composition

- 标题居中
- 四周留安全边距
- 默认透明背景
- 不加入正文
- 不加入人物
- 装饰元素最多 0–3 个

### Optional micro decorations

- 灯泡
- 星星
- 感叹线
- 小齿轮
- 小纸飞机
- 放大镜
- </>

装饰不能遮挡文字。

### Text accuracy

文字准确性为最高优先级。

必须逐字匹配用户输入：

- 不漏字
- 不多字
- 不换字
- 不加英文
- 不生成乱码

---

## A2. Chapter title

适合：

- 发现计算思维
- 认识算法
- 问题分解
- 动手编程
- 探究与实践

要求：

- 比主标题更简洁
- 保留橙红渐变、深棕描边、白色贴纸边
- 装饰减少
- 更强调可读性

## A3. Activity title

适合：

- 思考与练习
- 动动脑筋试一试
- 我的成长记录
- 合作交流

要求：

- 稍轻松
- 字体更圆润
- 可加入一个小图标
- 不要过度 3D

# Asset type B: Section labels

适合：

- 学习目标
- 单元导语
- 思考问题
- 我记住了
- 小提示
- 试一试

样式：

- 圆角胶囊 / 圆角矩形
- 暖橙或米杏底
- 深棕文字
- 左侧可配一个小图标
- 轻微投影
- 不使用厚重立体效果

---

# Asset type C: Icons

统一规则：

- 卡通扁平 + 轻微立体
- 粗细一致的圆润描边
- 透明背景
- 单图标独立输出
- 小学生友好
- 与教材主题色统一

推荐图标：

- 灯泡：想法
- 放大镜：观察
- 拼图：分解 / 组合
- 齿轮：机制 / 算法
- 靶心：目标
- 箭头：步骤
- 电脑：信息技术
- </>：编程
- 书本：学习
- 铅笔：记录
- 对话框：交流
- 小旗：挑战
- 星星：收获

---

# Asset type D: Mascot

基于用户提供的橙色果实吉祥物保持一致性。

必须保持：

- 头部轮廓
- 橙色果实外形
- 绿色叶片
- 大眼睛
- 白橙校服
- 红领巾
- 线条风格
- 主色关系

允许变化：

- 动作
- 表情
- 手势
- 道具
- 姿态

推荐动作：

- 挥手
- 举灯泡
- 拿放大镜
- 指向标题
- 拿铅笔
- 阅读
- 思考
- 点赞
- 庆祝
- 完成任务
- 指流程图

输出：

- 默认透明背景
- 单角色
- 不生成复杂场景

---

适合生成：

# Prompt construction

## Title prompt template

创建一个独立中文教材标题素材。

文字必须准确写为：

「{TITLE}」

风格：小学计算思维教材卡通立体贴纸标题字。

要求：

- 粗圆中文字体
- 暖橙到橙红渐变
- 少量左上高光
- 深棕粗描边
- 白色贴纸外轮廓
- 很轻的立体阴影
- 活泼、温暖、清晰
- 不要游戏 Logo 感
- 不要电商感
- 不要人物
- 不要页面
- 不要额外文字
- 不要英文
- 默认透明背景
- 四周留安全边距

## Mascot prompt template

基于既有橙色果实吉祥物形象，保持头部轮廓、绿色叶片、大眼睛、白橙校服和红领巾完全一致。

生成动作：

{ACTION}

要求：

- 小学教材插画风
- 角色比例稳定
- 面部特征稳定
- 线条清晰
- 色彩与教材统一
- 透明背景
- 不添加场景
- 不添加文字

## Icon prompt template

生成一个小学计算思维教材风格图标：

{ICON}

要求：

- 卡通扁平 + 轻微立体
- 圆润线条
- 以橙、暖黄、暖棕为主
- 可少量使用浅绿、浅蓝
- 独立图标
- 透明背景
- 无文字
- 无场景
- 适合教材排版

# Design principles

始终遵守：

1. 字 > 装饰
2. 清晰 > 花哨
3. 教材感 > 游戏感
4. 统一 > 炫技
5. 小学生亲和 > 幼儿化
6. 留白 > 堆元素
7. 信息层级 > 装饰密度

最终视觉应像：

> 同一本小学《计算思维》教材中自然延伸出来的统一资产。
