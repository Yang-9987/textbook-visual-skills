# Primary School Textbook Visual Skills

一套面向小学《计算思维》教材的统一视觉资产 Skill。

## 当前 Skill

`skills/primary-school-textbook-visual-system/SKILL.md`

用于生成：

- 卡通立体标题字
- 栏目标签
- 教材图标
- 吉祥物动作
- 装饰元素
- 页面辅助组件

## 核心风格

- 小学教材感，而不是游戏 Logo / 电商促销
- 温暖、活泼、清晰、克制
- 主色：#C87D4F
- 强调色：#C69A5E
- 重点色：#B2603C
- 暖棕：#8A5A3B
- 米杏：#F8EBE0
- 墨棕：#3D3630

## 快速用法

例如：

> 使用 primary-school-textbook-visual-system Skill，把“认识算法”做成章节标题素材，透明背景，不要人物。

更多案例见 `examples/`。
